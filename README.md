# Snake Game

A simple Python snake game built with `pygame`.

## How to run

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Start the game:
   ```bash
   python snake_game.py
   ```

## Controls

- Arrow keys: move the snake
- Enter/Space: restart after game over

## Objective

Eat the red food to grow the snake and increase your score. Avoid hitting the walls or yourself.
